# Руководство по установке и настройке LinuxOSZero в Oracle VM VirtualBox
# VirtualBox Complete Setup & Optimization Guide for LinuxOSZero v1.1.0 (Titan)

---

## 🇷🇺 Русская версия

### 1. Системные требования для виртуальной машины
* **Тип ОС**: `Linux`
* **Версия ОС**: `Other Linux (64-bit)` или `Ubuntu (64-bit)`
* **Оперативная память (RAM)**: от `2048 MB` (рекомендуется `4096 MB`)
* **Процессоры (CPU)**: `2 ядра` (включить `PAE/NX: ON`, `Long Mode: ON`)
* **Видеопамять (VRAM)**: `128 MB`
* **Графический контроллер**: `VMSVGA` (рекомендуется) или `VBoxSVGA`
* **3D-ускорение**: Включено (Checked)
* **Диск**: `20.00 GB` (динамический виртуальный диск VDI, контроллер SATA/AHCI)
* **Сеть**: `NAT` / `Сетевой мост` с адаптером `Intel PRO/1000 MT Desktop (82540EM)`
* **Мышь**: `USB Tablet` (Абсолютный курсор)

---

### 2. Пошаговая инструкция создания ВМ

#### Шаг 1: Создание новой виртуальной машины
1. Запустите **VirtualBox** и нажмите **Создать (New)**.
2. В поле **Имя** введите: `LinuxOSZero`.
3. В поле **Папка машины**: выберите желаемый каталог.
4. В поле **ISO-образ**: выберите файл `LinuxOSZero-v1.1.0-x86_64.iso` из папки `dist/`.
5. Поставьте галочку **Пропустить автоматическую установку (Skip Unattended Installation)**.
6. Нажмите **Далее (Next)**.

#### Шаг 2: Настройка оборудования (Hardware)
1. **Основная память (Base Memory)**: установите ползунок на `2048 MB` (или больше).
2. **Процессоры (Processors)**: установите `2 CPU`.
3. Убедитесь, что галочка **Включить EFI** не обязательна (поддерживается как гибридный MBR BIOS, так и UEFI).
4. Нажмите **Далее (Next)**.

#### Шаг 3: Настройка жесткого диска (Virtual Hard disk)
1. Выберите **Создать новый виртуальный жесткий диск (Create a Virtual Hard Disk Now)**.
2. Размер диска: `20.00 GB`.
3. Нажмите **Далее**, затем **Готово (Finish)**.

#### Шаг 4: Тонкая настройка графики и драйверов VirtualBox
1. Выделите созданную машину `LinuxOSZero` и нажмите кнопку **Настроить (Settings)**.
2. Перейдите во вкладку **Дисплей (Display)**:
   * **Видеопамять (Video Memory)**: выделите максимум — `128 MB`.
   * **Графический контроллер**: выберите `VMSVGA`.
   * Поставьте галочку **Включить 3D-ускорение (Enable 3D Acceleration)**.
3. Перейдите во вкладку **Система -> Процессор (System -> Processor)**:
   * Убедитесь, что включена опция **Включить PAE/NX**.
4. Перейдите во вкладку **Общие -> Дополнительно (General -> Advanced)**:
   * **Общий буфер обмена (Shared Clipboard)**: `Двунаправленный (Bidirectional)`.
   * **Функция Drag'n'Drop**: `Двунаправленный (Bidirectional)`.
5. Перейдите во вкладку **Общие папки (Shared Folders)**:
   * Нажмите `+` (добавить папку).
   * Путь: выберите любую папку на хосте.
   * Имя папки: `shared`.
   * Поставьте галочки **Авто-подключение** и **Создать постоянную папку**.
6. Нажмите **ОК**.

### 3. Исправление ошибки DisplayWrap (-52 / 0x8000ffff)

В версии **1.1.0 (Titan)** исправлен сбой ядра при входе в 64-битный режим x86_64 Long Mode. В предыдущих версиях дефект шага дескрипторов каталога страниц приводил к Guru Meditation, в результате чего интерфейс VirtualBox выдавал ошибку:
```text
Код ошибки: E_UNEXPECTED (0x8000ffff)
Детали результата: -52 (0xffffffcc)
Компонент: DisplayWrap
Интерфейс: IDisplay {14fd6676-ee6b-441a-988b-c83025ab693a}
```
В релизе 1.1.0 эта ошибка полностью устранена.

### 4. Управление клавиатурой и горячие клавиши

В релизе 1.1.0 доступен полный набор горячих клавиш:
* `Super` (клавиша Windows) или `Ctrl + Esc`: Открыть меню "ZERO OS"
* `Alt + F4`: Закрыть текущее активное окно
* `Alt + Tab`: Переключение между окнами
* `Ctrl + Alt + T`: Открыть терминал (ZeroTerminal)
* `Ctrl + Alt + E`: Открыть редактор (ZeroEditor)
* `Ctrl + Alt + F`: Открыть файловый менеджер
* `Ctrl + Alt + C`: Открыть панель параметров
* `Ctrl + Alt + I`: Открыть установщик
* `Alt + Shift`: Переключение раскладки клавиатуры (US / RU)
