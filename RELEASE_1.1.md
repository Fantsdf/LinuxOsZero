## 1. Главные изменения и нововведения в Release 1.1

В версии **1.1.0 (Titan)** проделана масштабная работа по устранению критических сбоев при загрузке, глубокой модернизации драйверов ввода и полной адаптации всех компонентов под **64-битный режим (x86_64 Long Mode)**:

- ✅ **Полное устранение ошибки VirtualBox `DisplayWrap / IDisplay {14fd6676-ee6b-441a-988b-c83025ab693a}` и `Guru Meditation 1155 (VINF_EM_TRIPLE_FAULT)`**:
  - Исправлен расчет секторов El Torito Boot Catalog: BIOS теперь считывает 512-байтовые виртуальные секторы (32 КБ ядра загружаются полностью).
  - Заменена RIP-относительная адресация при создании таблиц страниц на абсолютную адресацию через регистр `EDI` (`[edi]`).
  - Исправлен шаг дескрипторов каталога страниц (Page Directory Entry, PDE) — строго 8 байт на запись.
  - Настроено прямое отображение 4 ГБ физической памяти через 2 МБ Huge Pages (PML4 -> PDPT -> PD0..PD3).
- ✅ **Новый высокопроизводительный драйвер клавиатуры**:
  - Ядерный драйвер PS/2 контроллера (порты `0x60`/`0x64`) с обработчиком прерываний `IRQ1` (вектор 33 / `0x21`).
  - Декодер скан-кодов **Scan Code Set 1 и Set 2**, обработка префиксов `0xE0` (стрелки, Home, End, Del, PgUp, PgDn).
  - Поддержка модификаторов (Shift, Ctrl, Alt, CapsLock, NumLock) и переключения раскладки (US / RU) по `Alt+Shift`.
  - Пользовательский драйвер подсистемы Linux `evdev` (`/dev/input/event*`) и терминальный парсер ANSI-последовательностей.
- ✅ **Интерактивный терминал и текстовый редактор**:
  - `ZeroTerminal`: интерактивный ввод команд, история команд (`Up`/`Down`), мигающий курсор, автодополнение по `Tab`, выполнение встроенных утилит (`help`, `uname`, `vbox`, `zpkg`, `fetch`, `ls`, `cat`, `date`, `whoami`, `uptime`, `free`, `ps`, `calc`, `matrix`, `theme`, `clear`).
  - `ZeroEditor`: полноценный текстовый редактор с поддержкой набора текста, переноса строк, клавиш стрелок, Backspace, Tab, сохранения и открытия файлов.
- ✅ **Нативная архитектура x86_64**:
  - 64-битные сегменты кода и данных (`CS=0x18`, `DS=0x10`), 16-байтовые шлюзы IDT, выравнивание стека по 16 байт, прямое отображение 4 ГБ физической памяти.
- ✅ **Полный медиа-пакет релиза (168 МБ)**:
  - Загрузочный гибридный ISO-образ `LinuxZero.iso` (168 МБ) с полным набором тем оформления, фонов рабочего стола и сгенерированных WAV-звуков интерфейса.

## 2. Подробный разбор и исправление ошибки VirtualBox DisplayWrap и Guru Meditation 1155

### Симптомы проблемы
```text
00:00:24.663542 Changing the VM state from 'RUNNING' to 'GURU_MEDITATION'
00:00:24.663845 !! VCPU0: Guru Meditation 1155 (VINF_EM_TRIPLE_FAULT)
00:00:24.664251 CPUM0: 0018:0000000000000003 f0 53 Illegal opcode
```

### Первопричины:
1. **Размещение стека в области BIOS ROM (`0x000F0000 - 0x000FFFFF`)**:
   Инструкция `mov rsp, 0x100000` устанавливала указатель стека ровно на границу 1 МБ. Поскольку стек x86 растет **вниз** (`push` сначала декрементирует `RSP`), все стековые фреймы и адреса возврата функций попадали в диапазон `0x000F0000 - 0x000FFFFF`. В архитектуре IBM PC и в гипервизорах (VirtualBox, QEMU) этот диапазон является теневой областью системного BIOS ROM (`Write PC BIOS - 0xfffff`), в которой любые операции записи игнорируются. В результате вызов `call gdt_init` записывал адрес возврата в защищенную область ROM, запись отбрасывалась, и инструкция `ret` в `gdt_init()` считывала из стека нули (`0x0000000000000000`), совершая переход на адрес `0x0` (таблицу векторов IVT) и вызывая Guru Meditation 1155 (Triple Fault).
2. **Недогрузка тела ядра в BIOS El Torito**:
   В `builder/iso_creator.py` поле `Sector Count` спецификации El Torito заполнялось числом 2048-байтовых секторов вместо 512-байтовых виртуальных секторов. В результате VirtualBox считывал в память по адресу `0x7C00` только первые 5.5 КБ ядра, оставляя остальную часть кода неинициализированной.
3. **RIP-относительная адресация в 64-битном ассемблере**:
   Инструкция `mov dword ptr [0x9000], 0xA003` при ассемблировании в 64-битном режиме транслировалась компилятором как `movl $0xa003, 0x9000(%rip)` (запись по смещению `0x19000+` вместо абсолютного физического адреса `0x9000`). Из-за этого корень PML4 оставался пустым (все нули), что вызывало отказ страницы `#PF` при обращении к памяти.
4. **Шаг в 4 байта в 64-битном каталоге страниц**:
   Шаг `add edi, 4` перекрывал 64-битные дескрипторы PDE, формируя недопустимые базовые адреса фреймов памяти.
5. **Вызовы инструкций SSE до включения бита `CR4.OSFXSR`**:
   Компилятор GCC при `-O2` автоматически векторизовал цикл заполнения 256 шлюзов IDT 128-битными SSE-инструкциями (`movdqu`, `movdqa`, `psrlq`). При отсутствии бита `CR4.OSFXSR` (0x200) в регистре управления выполнение этих инструкций вызывало исключение `#UD` (Invalid Opcode).
6. **Выравнивание таблицы `isr_stub_table`**:
   Отсутствие директивы `.align 16` в секции `.rodata` перед таблицей 64-битных указателей векторов прерываний приводило к невыровненному чтению адресов шлюзов IDT.

### Исправление:
- **Перемещение стека ядра в оперативную память**: указатель стека `RSP` перенесен на `0x200000` (2 МБ), благодаря чему стек ядра растет вниз внутри полностью доступной для записи расширенной памяти (Extended RAM `0x00100000 - 0x001FFFFF`, 1 МБ чистой RAM).
- **Синхронизация CS в 64-битном режиме**: в `gdt_init()` после выполнения `lgdt` селектор `CS` обновляется через дальний возврат `lretq` (`pushq $0x18`, `leaq 1f(%rip), %rax`, `pushq %rax`, `lretq`).
- **Выравнивание `isr_stub_table`**: добавлена директива `.align 16` перед массивом указателей в `src/kernel/isr.s`.
- **Флаги компиляции freestanding ядра**: в `builder/build-kernel.sh` добавлены флаги `-mno-red-zone -mno-sse -mno-sse2`, исключающие повреждение 128-байтовой красной зоны прерываниями и блокирующие автовекторизацию в раннем коде ядра.
- **Включение `CR4.OSFXSR` и `CR4.OSXMMEXCPT`**: в `src/boot/stage2_trampoline.s` в регистре `CR4` устанавливаются биты `0x620` (`PAE | OSFXSR | OSXMMEXCPT`), а в `CR0` сбрасывается бит эмуляции `EM` и устанавливаются биты `MP | NE | PG | PE`.
- **Исправление El Torito**: в `builder/iso_creator.py` расчет секторов переведен на 512-байтовые виртуальные секторы: `boot_sectors = max(4, (boot_data_len + 511) // 512)`.
- **Таблицы страниц**: в `src/boot/stage2_trampoline.s` все обращения к PML4 (`0x9000`), PDPT (`0xA000`) и каталогам страниц (`0xB000..0xE000`) переведены на абсолютную адресацию через регистр `EDI` (`[edi]`) с шагом 8 байт на дескриптор.

## 3. Новая архитектура драйверов клавиатуры

В Release 1.1 реализована двухуровневая система обработки клавиатурного ввода:

```
[ PS/2 Keyboard Hardware (Port 0x60/0x64) ]   [ Linux Evdev (/dev/input/event*) ]   [ Terminal TTY / Stdin ]
                     |                                       |                               |
        [ IRQ 1 Interrupt ISR (0x21) ]                       |                               |
                     |                                       |                               |
        [ PS/2 Scancode Decoder (Set 1/2) ]                  |                               |
                     \_______________________________________|_______________________________/
                                                             |
                                              [ Input Subsystem Ring Buffer ]
                                                             |
                                            [ ZeroWM Keyboard Dispatcher ]
                                                             |
                                      +----------------------+----------------------+
                                      |                      |                      |
                              [ ZeroTerminal ]         [ ZeroEditor ]        [ ZeroInstaller ]
```

### Возможности клавиатурного драйвера:
1. **Аппаратный уровень ядра (`src/kernel/keyboard.c`)**:
   - Инициализация контроллера клавиатуры i8042 (`0xAE` - Enable Port, `0xF4` - Enable Scanning).
   - Регистрация шлюза прерывания IRQ1 в IDT (вектор 33 / `0x21`).
   - Асинхронное чтение скан-кодов без задержек основного цикла.
   - Поддержка составных последовательностей `0xE0` (расширенные клавиши: Стрелки, Home, End, Del, PgUp, PgDn).
   - Управление LED-индикаторами клавиатуры (Caps Lock, Num Lock, Scroll Lock).
   - Переключение раскладки клавиатуры `Alt + Shift` (US QWERTY / RU JCUKEN).
2. **Пользовательский уровень (`src/drivers/input.c`)**:
   - Автоматический поиск и опрос всех узлов `/dev/input/event0` .. `/dev/input/event15`.
   - Поддержка `libinput` / `evdev` структуры `struct input_event` (`EV_KEY`).
   - Фоллбек на сырой режим терминала `termios` с разбором ANSI escape-последовательностей.
3. **Глобальные горячие клавиши рабочего стола**:
   - `Super` / `Windows Key` или `Ctrl + Esc`: Открыть/закрыть меню "ZERO OS".
   - `Alt + F4`: Закрыть активное окно.
   - `Alt + Tab`: Переключение между открытыми окнами.
   - `Ctrl + Alt + T`: Быстрый запуск терминала.
   - `Ctrl + Alt + E`: Быстрый запуск текстового редактора.
   - `Ctrl + Alt + F`: Быстрый запуск файлового менеджера.
   - `Ctrl + Alt + C`: Быстрый запуск панели управления.
   - `Ctrl + Alt + I`: Быстрый запуск мастера установки.

## 4. Адаптация и исправление под чистую 64-битную архитектуру (x86_64)

Вся кодовая база проверена и переведена на стандарт **AMD64 / x86_64**:
1. **GDT (Global Descriptor Table)**:
   - Селектор `0x08`: 32-bit Protected Mode Code.
   - Селектор `0x10`: 64-bit Flat Data Segment (`DS`, `ES`, `SS`, `FS`, `GS`).
   - Селектор `0x18`: 64-bit Long Mode Code Segment (`CS`, `L=1`, `D=0`).
2. **IDT (Interrupt Descriptor Table)**:
   - Все 256 шлюзов сконфигурированы как 16-байтовые 64-битные шлюзы прерываний (`base_lo`, `base_mid`, `base_hi`, `ist=0`, `flags=0x8E`, `sel=0x18`).
3. **Выравнивание и размещение стека**:
   - Стек ядра размещен по адресу `0x200000` (2 МБ) в оперативной памяти Extended RAM и строго выровнен по 16-байтовой границе (`rsp & -16`) в соответствии с System V AMD64 ABI.
4. **VMMDev коммуникационный канал**:
   - Запросы VMMDev размещены в статических 16-байтовых выровненных буферах (`__attribute__((aligned(16)))`) в физической памяти до 4 ГБ.

## 5. Интерактивные приложения и окружение ZeroDesktop

### ZeroTerminal (Интерактивная командная строка)
- Поддержка набора символов с клавиатуры в реальном времени.
- Удаление символов по `Backspace` и `Delete`, навигация курсора `Left`/`Right`/`Home`/`End`.
- История введенных команд: клавиши `Up` и `Down`.
- Автодополнение команд по клавише `Tab`.
- Встроенные системные команды:
  - `help` — список команд.
  - `uname -a` — архитектура ядра и ОС (`Linux linuxoszero 6.1.0-zero-titan #1 SMP PREEMPT x86_64`).
  - `vbox` — статус интеграции с VirtualBox и отчет об исправлении DisplayWrap.
  - `zpkg list` — список установленных пакетов.
  - `fetch` — вывод системной информации и стилизованного ASCII-логотипа.
  - `ls` — просмотр директорий корневой файловой системы.
  - `cat <file>` — вывод содержимого файлов.
  - `calc <expr>` — математический калькулятор.
  - `theme <dark|light>` — мгновенная смена темы оформления.
  - `clear` — очистка терминала.
  - `matrix` — цифровая демонстрация.

### ZeroEditor (Интерактивный текстовый редактор)
- Многострочный буфер редактирования с нумерацией строк.
- Подсветка синтаксиса языка C (комментарии, директивы препроцессора, ключевые слова, строки).
- Навигация стрелками (`Up`, `Down`, `Left`, `Right`), клавиши `Enter`, `Backspace`, `Tab`.
- Кнопки тулбара: "Save" (`Ctrl+S`), "Open" (`Ctrl+O`), "Clear" (`Ctrl+N`).
- Статусная строка с отображением номера текущей строки, столбца и кодировки (UTF-8).

## 6. Инструкция по установке и настройке в VirtualBox

Для гарантированной работы рекомендуется следующая конфигурация:

| Параметр | Рекомендуемое значение | Примечание |
| :--- | :--- | :--- |
| **Тип ОС** | `Linux` | Обязательно |
| **Версия ОС** | `Other Linux (64-bit)` или `Ubuntu (64-bit)` | Включает флаги 64-бит |
| **Оперативная память (RAM)** | `2048 MB` (или `4096 MB`) | Рекомендуется |
| **Процессоры (CPU)** | `2 CPU` | Включить `PAE/NX: ON` |
| **Видеопамять (VRAM)** | `128 MB` | Рекомендуется максимум |
| **Графический контроллер** | `VMSVGA` (или `VBoxSVGA`) | Полное 3D/2D ускорение |
| **3D-ускорение** | `Включено (Checked)` | Аппаратный рендеринг |
| **Диск** | `20.0 GB (VDI dynamic)` | Контроллер SATA / AHCI |
| **Мышь** | `USB Tablet` (Абсолютный курсор) | Плавный ввод без захвата |
